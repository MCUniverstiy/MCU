# 📘 MCU Institute — Administrator Operations Manual

Welcome to the **MCU Institute Operations Manual**! This guide is written specifically for administrators, interns, and course managers. It contains step-by-step instructions for managing every part of the MCU web platform with zero technical jargon.

---

## 🔑 Quick Start: Logging In

1. Open your web browser and go to:  
   **`https://your-mcu-site.com/login`** *(or click **Login** in the top navigation menu)*.
2. Enter your admin login credentials:
   * **Email Address:** `mcuinstitute@gmail.com`
   * **Password:** `12345678`
3. Click the red **Sign In →** button.
4. Once signed in, navigate to the **Admin Dashboard** (`/admin/cms`) to access all management controls.

## 💡 Key Terms Explained Simply

* **CMS (Content Management System):** The control panel where you edit what visitors see on the website without needing to code.
* **Enrollment:** A student registering and paying for a course.
* **Google Classroom Link:** A web address connecting an MCU course to a Google Classroom, enabling automatic invitation emails upon payment.
* **Membership Discount:** A percentage discount (e.g. 10% off) automatically applied to course purchases for active VIP members.
* **Pass / Fail Grade:** Marking a student as *Pass* automatically generates an official digital completion certificate for them.
