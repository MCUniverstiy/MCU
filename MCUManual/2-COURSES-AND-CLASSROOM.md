# 📚 Courses & Google Classroom Management Guide

**URL:** `https://your-mcu-site.com/admin/cms/courses`

This guide explains how to manage course listings, prices, instructor assignments, and link courses directly to **Google Classroom**.

---

## 🎯 What This Section Does
Courses managed here are displayed on the main **Courses** page (`/courses`). Students can browse programs, filter by category, view course details, and enroll online.

When a course is linked to a Google Classroom, paying students automatically receive an invitation email to join that Google Classroom roster!

---

## ➕ How to Create or Edit a Course

1. Navigate to **Content Manager → Courses** (`/admin/cms/courses`).
2. Click **`+ Add course`** (or click **Edit** next to an existing course).
3. The **Course Editor** sidebar will open on the right.
4. Fill out the fields:

| Field Name | Description & Example |
| :--- | :--- |
| **Title \*** | Full course name (e.g., `CEO Wealth Management Masterclass`). |
| **Category \*** | Topic area used for filter tabs on `/courses` (e.g., `Wealth Management`, `Financial Planning`, `Family Office`, `Executive`). |
| **Google Classroom Link or Class ID** | Paste the full link from Google Classroom (e.g., `https://classroom.google.com/c/ODY5MDk0NzIyMTAz`). |
| **Price (HK$) \*** | Course fee in HKD (e.g., `12500`). Set to `0` for free courses. |
| **Duration** | Expected length (e.g., `10 weeks` or `3 Days Intensive`). |
| **Level** | Experience level (e.g., `Foundation`, `Professional`, `Executive`). |
| **Format** | Learning mode (e.g., `Hybrid`, `Online`, `In-Person`). |
| **Instructor** | Select the instructor teaching this course from the dropdown. *(Instructors are created under Content Manager → Instructors)*. |
| **Description** | Summary covering course objectives, curriculum highlights, and who should attend. |
| **Course Photo** | Upload a high-resolution cover photo for the course card. |

5. Click **Save course**.

---

## 🏫 Linking Google Classroom (Step-by-Step)

1. Open a new browser tab and go to **[Google Classroom](https://classroom.google.com)** using your institute Gmail account.
2. Open the class created for your course (or create a new class).
3. Copy the URL from your browser's top address bar:
   `https://classroom.google.com/c/ODY5MDk0NzIyMTAz`
4. Return to the MCU Admin Course Editor and paste the copied link into the **Google Classroom Link or Class ID** box.
5. Click **Save course**.

### How to Verify the Link
Look at the course row in the course list on the left:
* **`🏫 Classroom Linked`** (Green) — Successfully connected!
* **`🏫 No Classroom`** (Red) — No Classroom link provided yet.

---

## 🔄 What Happens After a Student Enrolls?

1. When a student completes payment on the website, MCU receives confirmation.
2. MCU automatically sends a **Google Classroom Invitation Email** to the student's registered email address.
3. The student opens their email, clicks **Join**, and instantly gains access to the classroom materials!
